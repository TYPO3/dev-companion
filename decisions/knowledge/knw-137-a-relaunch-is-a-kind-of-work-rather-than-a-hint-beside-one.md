# D-KNW-137 — A relaunch is a kind of work rather than a hint beside one

**To carry a body of content that exists onto TYPO3 is a task intent whose
checklist states what the model owes. No hint repeats those statements beside
it.**

The session that reported this had already called `typo3_task_guide`, so the
brief is where the answer reaches it. A hint would be the same four sentences in
a second place, found by a query nobody made.

## Evidence

- The task text of 2026-08-31 named the migration, "Migrate content from a
  legacy Drupal 6 site". It matched `installation-setup`, `tca-field` and
  `site-setting` and nothing about the content model. Run through the matcher
  again on 2026-09-01 with the intent in place, it matches `content-relaunch`
  strongly. That intent stands before `installation-setup` in the catalog, which
  is the order the brief names the skills in.
- The session called `typo3_task_guide` twice, both in its first hour, and made
  no hint lookup about the model in five more. The brief is the surface it was
  actually on.
- The one statement in the checklist that is a claim about TYPO3 holds on both
  `.checkouts/main` and `.checkouts/13.4`. The `html` element's template is
  `<f:format.raw>{data.bodytext}</f:format.raw>`, so what an import stored is
  what a visitor gets.

## Decided

- The intent carries the statements. The model before the crawler, the shapes
  that recur as the elements, the `html` element as no migration target, and the
  count as an input.
- No `legacy-content-relaunch` hint. The same sentences in `knowledge/hints/`
  would be the second place one fact lives, which is what the corpus stands
  against.
- The intent sits before `installation-setup`, because what the feedback reports
  is an order rather than an absence. Both workflows existed and the scaffold
  came first.

## Assumed

- That a relaunch arrives through `typo3_task_guide`. A session that never calls
  it reaches none of this, and no hint answers the symptom either.

## Wrong if

- A session reports the model gap after it called no task guide, which would put
  the statements where a symptom finds them after all.
- The needles reach a task that upgrades code inside an installation rather than
  carries content into one.
  `KnowledgeTest::aBriefNamingOneKindOfWorkConfirmsThatKindAndNoOther` holds one
  brief per kind, and the weak needles — legacy, migrate, drupal — are the ones
  to watch.
