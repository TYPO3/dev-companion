# R-ANS-002 — The reason is in the data, not only in the text

text. `typo3_server_scope` carries the installation and console diagnostic as
data too.**

Nothing a caller needs in order to act lives in the text alone.

twice concluded an extension registered no icons and no labels (2026-07-29).
