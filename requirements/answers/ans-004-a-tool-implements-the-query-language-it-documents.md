# R-ANS-004 — A tool implements the query language it documents

**The query language a tool documents is the one it implements.**

Where the command behind it matches only a literal string, the tool composes the
search out of the words rather than hands the phrase through. So a multi-word
query means what the description says it means.

## From

Every multi-word label query came back empty, the tool's own documented example
included (2026-07-29).
