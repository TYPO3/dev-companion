# R-AUD-001 — Core, extension and site work are each served

**An answer is right for the work the caller asks from: core contribution,
extension development or site development.**

The same person is often two of them in one checkout, because people develop
extensions inside site installations. Where knowledge holds only for core
contribution it says so. A core checklist handed to an extension author is a
wrong answer rather than a partial one.

## Held by

- The two tests hold the operative half. The scope fails the day the site
  developer's knowledge goes, and the day it puts project and extension work
  back outside what the server answers. The second holds the same sentence where
  it is prose rather than a list. That is a tool description, the readme, a
  hint, the instructions a client receives.
- [`R-AUD-005`](aud-005-an-answer-says-who-it-obliges.md) holds the marks, and
  the [scope group](../scope/readme.md) says how the tools that exist today meet
  the rest of it. None of them holds the principle as one sentence.
