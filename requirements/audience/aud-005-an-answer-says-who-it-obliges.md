# R-AUD-005 — An answer says who it obliges

**An answer says who it obliges, not only what is true.**

The same sentence can be a condition of a core patch and a convention worth
adoption in a project. The sentence does not show the difference. So it is data
(`scope: "core"`). It stands on the hint where the whole subject is the core's
own, and on the statement where one sentence in a transferable hint is. What
only binds a core patch gets a mark outside the core rather than a drop. The
backend's design system is exactly what a project that builds a backend module
needs. This is
[R-AUD-001](aud-001-core-extension-and-site-work-are-each-served.md) made
specific. A core rule handed over as the rule is a wrong answer, and one handed
over as nothing is a second one.
