# R-DIS-014 — An installed skill is a workflow, not a prompt fragment

**Installed task skills are workflows with an evaluation behind them rather than
static prompt fragments.**

Task-shaped test and conformance work goes through the task guide before
subsystem evidence. Repeated test, audit, documentation and content-element
judgment lives in on-demand references. Each skill states what it owns, and a
skill offers core-only test guidance only when the active server profile
provides it. Realistic prompts and their acceptance criteria stay runnable
without tool names or intended answers. A check over the directory holds what
holds for a skill because it is one. So it holds a skill written later without
an entry in a list first. That is its published name, a description a client can
route on, and the sentence that says what it owns. It is a body that routes
rather than restates, and references one hop away that load on demand.

Forward tests of the testing, conformance, documentation, and backend module
skills against the Printworks sitepackage (2026-07-30).
