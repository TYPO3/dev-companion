# R-GUI-014 — A brief names the acts the workflow question is asked again at

**`typo3_task_guide` names the acts to call it again at.**

Those are a file under a test directory, a declared check, a branch or commit,
an edit to the shipped documentation.

Otherwise the question comes up once, against the request, which is the moment
the session knows least about what it will contain. The acts are what this
server can name without a look at the checkout. A session is inside a subject
before it can say which one. They belong in the brief rather than in the
`instructions`, which are 2038 characters of the 2048 a client keeps.

## From

`feedback/2026-08-18-081159`. A German symptom report about two TypoScript
conditions opened a session. It went on to an API removal on a major, two new
test directories and the repository's declared check suite. Three subjects have
an owner here and no skill fired for any of them. Measured in this worktree on
2026-08-18, the brief for each of those sub-steps names the skill and the guide
that own it. The brief for the first line names neither.
