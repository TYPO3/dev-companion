# R-KNW-006 — Where the core ships the example, the answer names it

**Where the core itself ships the worked example of a convention, the answer
names it instead of describes one.**

A theme extension is part of the core and is the reference a sitepackage stands
against, so this server covers it. The frontend-theming boundary excludes a
project's own CSS, not the core's own extension.

A sitepackage built with an invented directory layout, rejected with "die ordner
