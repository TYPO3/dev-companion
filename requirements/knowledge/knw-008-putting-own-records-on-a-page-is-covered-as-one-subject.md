# R-KNW-008 — Putting own records on a page is covered as one subject

**Records of an own table on a page are a subject of their own.**

That is the TCA-only table and the data processor chain that reads it. It is the
single view fed by a request argument, and the routing a site set ships for it.

It is what a site consists of and it belongs to no single domain, so a task that
names none of them reaches it.

## From

A product list, detail view and teaser element built for a sitepackage. The
answer gave backend-form and shipping-content hints while nothing had written
down the mechanism the whole task consists of (2026-07-29).
