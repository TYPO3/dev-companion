# R-PRJ-006 — What an extension does not ship is answered too

**An extension answer says what the extension ships beside its registrations,
and says it when the artifact is not there.**

Those are its manual, its README, the test layers it has, and its XLF files with
the source language each declares.

A reader finds everything else about an extension with a further read. These are
the ones with no file to find, so the answer states them rather than leaves them
to discovery. The answer reports the source language as the fact the file
states; which one it ought to be stays a convention in the knowledge base.

## From

Three `REVIEW-01` runs (2026-07-31). None of them reported that the site package
ships no manual. None of them reported the German `source-language` of its three
XLF files while they read them.
