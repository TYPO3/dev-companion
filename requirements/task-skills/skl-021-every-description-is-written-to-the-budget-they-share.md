# R-SKL-021 — Every description is written to the budget they share

**What the published descriptions cost together stays inside the listing budget
a client gives all of them at once.**

A description's own skill does not pay for it. The client reads every skill's
metadata in one attachment against one character budget. Where that runs out it
drops whole descriptions rather than shortens them. So a sentence added to one
description comes off the skill that ends up listed by its name alone. No
warning reaches the session it happened to.

## From

The measurement of 2026-08-08 in `D-SKL-026`. The twelve descriptions cost 7153
characters against a budget of 6000 for a 200k session on the current model
generation. The client's own bundled skills had already taken 5997 of it. What a
dropped description costs is `D-AUD-003`: a review prompt whose every criterion
the conformance skill would have met, which did not activate it.
