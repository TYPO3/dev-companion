# Cross-cutting

These are not about one audience. They are about the four situations every
audience runs into. A user who does not know what the server is for, and work
somewhere it cannot reach an installation. A task whose audience is ambiguous,
and a client that shows the agent only the data half of an answer. They are
contract cases with a target and not open forward reviews.

See [the contract readme](../readme.md) for the states and how to print one, and
[the scenario readme](../../readme.md) for the audiences and environments.
