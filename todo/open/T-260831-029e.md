# Say how many rows a table an extension declares actually holds

The modelling half of this feedback landed on 2026-09-01 and the feedback is
trimmed to what is left: whether `typo3_extension_describe` reports the row
count of each table the extension declares, so a caller being oriented sees the
scale that decides the editing surface rather than establishing it later. The
server already reads the installation. The step is what that costs and what it
may not do — a count is a query per table against a database this server has
never written to, and a describe answer is delivered before a task is known, so
whether it is worth the call is the question before the field. It touches a
declared `outputSchema`.
