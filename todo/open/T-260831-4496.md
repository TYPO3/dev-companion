# Say which language a project writes its code in

Ladder step 1b, and the small half of a feedback whose other half is the
model's: a convention stated five times over 80 minutes was carried out as four
bulk passes and then broken by the next new file, because a pass over what
exists does not reach what is written next. What this server can carry is the
orientation: `ExtensionDescribe` already reports the `source-language` each XLF
file declares, so the step is whether a project answer can state the code
language once, at the top, from what the repository declares — the XLF sources,
an `.editorconfig`, a contributing file. It touches a declared `outputSchema`,
so what it says and where it says it is decided before it is written.
