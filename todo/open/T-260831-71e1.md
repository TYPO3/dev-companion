# Settle what a hint carries beside its statements

Three feedback are trimmed to one question: what a hint entry holds that its
sentences do not. Two of them ask for a tool — `browser-tests` says nothing
about `typo3_test_run_guide`, `frontend-dataprocessors` nothing about
`typo3_configuration_lookup` — and the third asks for the unit a repair takes,
because a statement about one TCA option is fixed in one file and holds for
every table. A hint already carries `documents`, derived from the documents that
name it, so the shape exists and the question is whether either of these is a
field beside it or a sentence inside the statements the matcher already
searches. Both change what every entry is, so the shape is settled before an
entry gets one. `D-ANS-129` is the same move on the describe answer and what it
rejected there.
