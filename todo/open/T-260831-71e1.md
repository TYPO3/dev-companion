# Have a hint answer name the tool its subject implies

The describe answer names the next call since `D-ANS-129`, and both feedback are
trimmed to what that did not reach. A hint answer already carries a `documents`
array and nothing that names a tool, so `browser-tests` says nothing about
`typo3_test_run_guide` and `frontend-dataprocessors` nothing about
`typo3_configuration_lookup`. The step is where such a name lives: a field on
the hint beside `documents`, which is data every consumer reads, against a
sentence in the hint text, which is prose the matcher also searches. Both change
what a hint is, so the shape is settled before an entry gets one. The other half
left open is `D-ANS-129`'s neighbour — an answer that reports a resolved value
saying so and saying what the file it was resolved from carries.
