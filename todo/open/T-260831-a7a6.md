# Report what a TypoScript setup defines, not only its file name

Ladder step 1b: `typo3_extension_describe` on `fluid_styled_content` reports
`contentElements: []` and the file names of its TypoScript, and never names
`lib.contentElement` — the one object a sitepackage takes the dependency for.
The caller read the empty list as the extension being inert for it. The step is
whether the top-level objects a setup defines can be reported beside the files,
which is a reading of what `Installation/` can establish without booting, and it
touches a declared `outputSchema`. The second step is the decision itself as a
hint: what `lib.contentElement` and `lib.parseFunc_RTE` buy, what
`fluid-styled-content-css` buys a site that hides every element it styles, and
what defining your own costs.
