# State that an assertion is evidence once it has been seen to fail

Ladder step 1a with the concept already in the corpus for one subject:
`any/testing/proving-a-condition` carries the negative control that makes one
result evidence, for a TypoScript condition, and nothing says it for a browser
suite — where 107 green tests ran through 118 broken records and two assertions
in a row could not fail. Write it into `project/testing/playwright` and the
`browser-tests` hint: break the thing, watch it go red, restore, watch it go
green, both directions; then the three shapes that pass silently — a locator
matching nothing, a substring found in the module chrome, an assertion on text
the module never emits. The backend module route this session asserted against
is the fourth and is verified against `.checkouts/` first.
