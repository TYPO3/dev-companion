# Say at the foot of a brief when it has to be asked again

Two feedback are trimmed to the same ask. The server's `instructions` already
say to call `typo3_task_guide` again at the first test, check, commit or shipped
file the task did not name, and one session read that once at 18:38 and never
acted on it — the brief was called twice in five hours, both times in the first
one, while the rename, the icons, the harness and the README all went past. The
step is whether a brief closes on the events that make it stale, named
concretely, and what those events are per intent rather than in one sentence for
all of them. It changes what every answer of that tool weighs, so
`bin/cli tools:measure` is what says what the line costs before it is written.
