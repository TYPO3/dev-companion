# Settle what a tool that reads records may answer

The maintainer said on 2026-09-01 that counting rows is not
`typo3_extension_describe`'s work and that reading records is worth a tool of
its own, which is this entry's boundary rather than a field on an existing
answer. Write the decision that moves it, and settle these before any code: what
a caller asks it — a table, a page, a query — and what comes back; which of the
six verbs it takes, since a query going in and matching entries coming out is
`lookup`; what it refuses, because `doesNotCover` says today that a record is
the installation's own and the trust argument under that is the shell user's
access; whether the probe may run a data query at all, having never run one; and
what the answer says about an installation's content to whoever started the
process. The sighting is in `feedback/archive/2026-08-31-233952`: 3101 rows in
one storage folder, a record list that takes minutes, and a session that read
the count twice and drew nothing from it.
