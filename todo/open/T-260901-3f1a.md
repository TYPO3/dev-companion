# Give the record count an environment that can answer it

The tool is built and its central case is recorded nowhere. Neither recording
environment can produce it: `E-SITE` has no extension of its own, so every table
is refused there, and the fixture installation below `.fixtures/installation`
has the extension but no TYPO3 to open a connection with — its recorded answer
is `installation-not-answering`. The query itself was run by hand against the
running `E-SITE` 14.3 on 2026-09-01 and grouped correctly, so what is missing is
the environment rather than the code. Either give
`bin/cli environment:create E-SITE` an extension of the project's own with a
table and rows in it, or say in `documentation/records/` that this one answer is
held by `RecordLookupTest` alone and why. `FixtureTest` skips the call by its
label today, which is the second place that decision is written.
