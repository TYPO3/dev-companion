# Give each audit surface an id it can be named by

The seven surfaces of `typo3-extension-health`'s checklist are prose bullets, so
the report that closes on them restates the words, a finding cannot name the one
it came from, and a run's judgment invents its own. Give each surface an id and
one entry of its own in the checklist, and have the skill's report step name the
id beside the mark rather than the sentence. Do it in that one checklist first
and leave the other seven alone: what has to be shown is that a report gets
shorter and a judgment gets comparable across two runs, which one checklist
answers as well as eight. `R-SKL-013` asks a surface reported as assessed to
name what was read, and an id is what lets the two runs be read against each
other at all.
