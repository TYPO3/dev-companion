# Name the files a change will touch before the first edit

`typo3-extension-health` writes its list down and has it agreed before anything
changes, and the other skills that end in a change do not: the crossing rule
says where to stop editing, never what the edit is about to be. Add one step to
`skills/base.md`, at the point the work turns from reading to writing: the
session names the files it will create, change or delete, and a deletion is
taken only where the caller has said so. It sits in the base rather than in each
body because a skill lands in somebody else's checkout, where an unannounced
deletion is the one finding nothing here can take back. Read the health skill's
agreed-list section first — where the base carries this, that section is what it
adds on top rather than a second copy.
