# Catch the tool nobody can choose between at the moment it is added

`typo3_record_lookup` was added on 2026-09-01 with a green suite, a `covers`
entry, a routing line and a recorded page, and a caller holding its name beside
`typo3_schema_lookup` still had nothing to choose on: neither description named
the other, and the initialize index carries neither because it is six entries
against a fixed budget of 2048 characters, of which 1948 are spent. It was found
by asking, not by a check.
`ScopeTest::theTwoLookupsThatBothReadAsATableQuestionNameEachOther` now holds
that one pair, as `D-ANS-072`'s own test holds the hint and rule pair — one test
per pair somebody noticed. Read the thirty-one descriptions for the pairs nobody
has noticed yet, and settle whether "adjacent" can be made checkable at all: a
candidate is any two tools whose `covers` entries share a subject, which is data
rather than judgement. Where it cannot, say so in `D-ANS-072` and make the
pairing a step of adding a tool instead.
