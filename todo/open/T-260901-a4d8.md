# Write the failure three reviews restate once

Each forward review carries a **How it fails** list, and the same failures are
written three times in three wordings: the generic checklist instead of this
checkout, the invented requirement, the missing source read as an absent
feature. Read the three lists together, mark every failure that appears in more
than one, and write each of those once where a review can name it instead of
restating it. The archived feedback is where a fourth comes from, so read it in
the same pass rather than in a second one. What the reviews keep is what is
theirs alone — a failure that only this prompt can produce — and the shared ones
become a name a run's judgment can be read against.
