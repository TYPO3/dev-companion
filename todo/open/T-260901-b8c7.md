# Build the tool that counts a project-owned table's rows

`D-AUD-016` settled what it answers on 2026-09-01 and nothing is written yet.
One class in `src/Tool/`, a `lookup` on the subject `record`, taking a table and
answering `COUNT(*)` grouped by `pid` and by the state the enable fields put a
row in, with the deleted and the hidden counted apart rather than folded in. It
refuses every table a project-owned extension does not register, which
`typo3_project_describe` and `typo3_extension_describe` already establish
between them. The query is a topic of `src/Installation/probe.php`, asked for
the way `liveSchema` is rather than read with everything else, and the answer
says it was read with the shell user's database access and no backend
permissions. Then the three outward surfaces: the `doesNotCover` entry in
`knowledge/server-scope.json` that says today no tool touches a row, `covers`
and `routing` beside it, and the contract test every tool takes.
