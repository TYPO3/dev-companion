# The computed domain says where it is written

`typo3_translation_domain_lookup` answers `core.core` and stops. The same value
is what a backend module imports as `~labels/core.core`, and a caller holding
the domain has to know that by itself — the corpus states the import form in
`javascript-labels`, one call away, and the tool that computes the value does
not name it.

The answer half is the reading: the import exists from the major the bundle
does, so a domain computed for an older target is not one to write into an
import at all, and the tool already knows which target it answered for. Read
`src/Tool/TranslationDomainLookup.php` and `D-KNW-005` for what the answer may
say, and add the field rather than widening the text — a description is not
where a value goes.
