# Read what a task actually uses of the largest skill body

`typo3-development-installation` injects 21 KB into every session that activates
it, and a task takes one of its branches: the declared installation booted, the
one created from nothing, or the one that already answers. Read that body
against the branches, mark which sections a single task uses, and move one
branch behind the dispatch line into `references/` — the file is loaded when the
branch fires and not before. What decides whether it can move is the routing
rule: `SkillTest::everySkillRoutesThroughTheOwnersOfItsOwnFactsInOrder` asserts
a tool's name in `SKILL.md`, so a branch carrying a routed call cannot leave the
body until that assertion reads the reference too. Report the measurement either
way, because the other four bodies over 17 KB are the same question and this is
the one that answers it first.
