# The triage skill's steps are numbered as one order

`skills/typo3-core-issue-triage/SKILL.md` numbers steps 1-2, then fifty lines of
bold prose, then 3, then 4-5, then 6-9 under "What a previous attempt cost",
which applies only where a fix was reverted — so 6-9 read as owed on every issue
and the order cannot be read off the prose. Number the unconditional order as
one list and make 6-9 an unnumbered sub-procedure of the section that conditions
them; `SkillTest` holds the sentences, not the numbers.
