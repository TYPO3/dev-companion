# The inline relation facts in the content element checklist get a hint

`skills/typo3-content-element-development/references/checklist.md` states
"explicit parent field and `foreign_field`; explicit sorting and
`foreign_sortby`", and `SKILL.md` names `type=inline`; nothing below
`knowledge/` carries `foreign_sortby`, so this is a TYPO3 fact stated
permanently in a published file with no lookup behind it. Verify what an inline
child table needs against the covered checkouts below `.checkouts/`, write it as
a hint in `knowledge/hints/` bound to the majors it holds on, and route the
checklist to `typo3_hint_lookup` with that id in place of the sentences.
