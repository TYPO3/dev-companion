# A single changelog entry carries its Migration section

Taken on, `D-ANS-139`. `Installation\Changelog::read()` already opens the
entry's own file and parses the title, the index tags and the stated removal out
of it. The Migration section sits in the same file between `Impact` and the end,
and a sweep that returned 75 titles cost the session two file reads for the two
it acted on.

First step: parse that section beside the three fields already taken, and carry
it where the call names one entry — an issue number, or a query that matched
one. A sweep keeps the titles: 75 migrations is not an answer.

What is still to establish is the shape a deprecation entry writes it in, and
whether the Breaking, Feature and Important types carry something in its place.
Read the files under `.checkouts/*/typo3/sysext/core/Documentation/Changelog/`.
