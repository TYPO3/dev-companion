# A system extension key resolves to the Forge area it is filed under

Judged as `D-ANS-142`, which carries the measurement: 19 of the 38 system
extensions reach exactly one area through `Forge::named()` and the rest reach
none. **The step.** Curate the mapping for the ones that reach none — the entry
is the extension key and the area name in the tracker's own spelling — beside
`knowledge/catalog/system-extension/entries.json`, then have `Forge::named()`
fall back to it where the caller's word matched no area, and say in the answer
which mapping was used. Write the check that reads every mapped name against
`Forge::categories()` in the same commit, because a renamed area is what makes
the file wrong and nothing else would report it. The composer title is not the
route: `D-ANS-142` measured what it resolves and what it gets wrong.
