# The project answer names a kind of file no command checks

Judged as `D-ANS-148`, which sets the boundary: what is said is the kind nothing
covers, never what to add. **The step.** Write the tool-to-kinds map — the
checkers a project package is checked by, `php-cs-fixer`, `phpstan`,
`stylelint`, `prettier`, `eslint`, `tsc`, `xliff-lint` and the rest — beside
`Project::runs()`, which already reduces a declared line to the tool in front of
it. Then read the kinds the project's own packages ship, subtract what the map
says the declared commands cover, and carry the remainder in the answer beside
`commands`. A command whose tool the map does not know covers nothing knowable
and is reported as that rather than as covering nothing.
