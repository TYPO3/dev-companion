# Put the file list behind a parameter and say what a change answer carries

Give the `change` and `commit` forms of `typo3_gerrit_lookup` a `files`
parameter — `none`, `stat`, `full` — defaulting below `full`, and leave every
other field of a named read where it is; `D-ANS-151` names the ones four
sessions said must survive and why. Then rewrite the description around what the
answer actually carries rather than what it is: `chain` with `chainedAt`,
`mergeable`, `fetch.ref`, the commit message body and the `path` way in, and one
sentence saying `fetch.ref` is handed to `git fetch` because reading the diff
happens in the checkout. `GerritTest` holds the fields today, so the new
parameter is held there beside them.
