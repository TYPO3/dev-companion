# The installer writes a block of its own into the project's instruction file

Have `src/Server/Installer.php` append a block it owns to the project's agent
instruction file, `AGENTS.md` or the file the chosen client reads, and rewrite
that block on `update`. The maintainer chose this shape on 2026-09-19 over a
printed snippet and over writing nothing. It is the one channel `D-SKL-033` and
`D-SKL-038` name as untried after four sessions without an activation, and the
core's own `AGENTS.md` is what beat the skills there. The block is marked at
both ends so a person sees what put it there, and it says what the skills are
and that a task starts by activating the one that covers it. Nothing outside the
marks is touched, and a file without the marks gets the block appended. Say in
`documentation/usage/` what the block is and how to take it out. Then write the
shape into `D-SKL-033` under **Decided**, and archive the three feedback with
`bin/cli feedback:archive`.
