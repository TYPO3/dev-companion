# Say in the base what a schema search has to be passed, and what a carried patch produces

Two clauses in `skills/base.md`, both reported by a session that followed it
correctly and paid for what it does not say. The qualified name is not only what
a presence check looks for but what a schema search has to be given: a `select:`
query on the bare names returns nothing where the tools are there, so the first
call of the session fails before anything is established. And the sweep
exemption turns on what the task produces, which leaves carrying somebody else's
patch onto current code with two defensible readings — it writes commits, and
the API surface in them is the patch author's. Say which. `SkillTest` holds the
base's order, and `Installer` copies the file into every published skill, so the
edit reaches a project at its next install.
