# Give the commit message guide the work-in-progress state, and the counts check

`typo3_commit_message_guide` raises `missing-issue` as an error on a change
marked `[WIP]`, which `core/contribution/commit-messages` says is not offered
for merge at all — so a trailer the merge requires is being demanded of a
message that is not asking for one. Read `[WIP]` and `[POC]` out of the subject
the call already passes, or take the state as a parameter, and drop the
merge-required trailers to findings there; the sign-off rule itself is not in
question and stays where `R-KNW-075` puts it. In the same pass add the counts
check: a body naming how many files, occurrences or spellings a change touched
is what `D-KNW-155` measured and the page now carries. `CommitMessageTest` holds
the checks per workflow.
