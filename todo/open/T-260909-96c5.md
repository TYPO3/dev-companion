# Join the two ends of the prior-art route

Three edits, all decided in `D-ANS-153`. Say in `typo3_forge_lookup`'s
description that a query reaches only text somebody wrote, so an issue whose
description is empty is reachable by its subject alone, and that the way in for
"has anybody attempted this" is `typo3_gerrit_lookup` by repository path,
following the change's `issues` back to the ticket. Then make an empty `issues`
on an open change a stated absence rather than an empty array, naming that
`Resolves:` is required before the change can be pushed and that
`typo3_forge_lookup` says whether an issue already exists. `ForgeTest` and
`GerritTest` are where the two ends are held. The subject-only fallback the
report asks for is declined and the decision carries the measurement, so it is
not to be built back in.
