# Rewrite what a session imitates, starting with the briefs and the hints

Sweep the surfaces a caller reads as an instruction and copies — the checklist
items `typo3_task_guide` returns, the hints, and the reference files the skills
ship — and rewrite each line that has to be read twice. Name the actor, one
thought per sentence, no colon carrying the content, no trailing preposition, no
metaphor the codebase does not use. Tool descriptions come after those, because
a description is read once while choosing and a brief is copied into a patch.
Judge each line rather than substituting: of the six plain versions the feedback
offers, three cost more tokens than the original and one breaks the ruleset's
own first rule, which `D-DOC-068` measured. Where a rewrite would push the
`instructions` or a description past the budget `D-ANS-004` and `D-SKL-026`
measured, that is the entry's second **Wrong if** and the finding to report
rather than a line to squeeze.
