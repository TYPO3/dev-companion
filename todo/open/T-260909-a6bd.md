# Rewrite what a session imitates, one line at a time

Sweep the surfaces a caller reads as an instruction and copies, in this order:
the 143 checklist items in `knowledge/task-intents.json`, then the hint lines,
then the skills' reference files. Tool descriptions come last, a description
being read once while choosing where a checklist item is copied into a patch.
Rewrite each line that has to be read twice: name the actor, one thought per
sentence, no colon carrying the content, no metaphor the codebase does not use.
Read each line rather than matching a pattern — `D-DOC-068` measured what a
mechanical pass returns, and most of its 16 trailing prepositions are ordinary
relative clauses while only about half of its 50 colons are the defect. Where a
rewrite would push the `instructions` or a description past the budget
`D-ANS-004` and `D-SKL-026` measured, report that rather than squeezing the
line. `bin/cli prose:check` counts the long sentences and none of these rules,
so what holds this is a reader.
