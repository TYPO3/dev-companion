# Say how asset publishing is exercised in a functional test

Write what a functional test meets when it drives
`DefaultSystemResourcePublisher`, bound from 14 because
`typo3/sysext/core/Classes/SystemResource/` exists on `14.3` and `main` and on
neither older branch. Three facts, the first two already read in `.checkouts/`
and carried by `D-KNW-156`: the shipped default of
`SYS/SystemResources/filesystemPublishingType` is `link`, so the symlink
publisher is active and the `auto` resolution against the application context
never runs unless something sets `auto` back; and publishing is skipped for any
resource whose package path plus relative path starts with the public path,
which in an instance where the project path is the public path is all of them.
The third is what still has to be established there: what has to be at the
publishing target for the symlink strategy to fail rather than report a success
— the report says a regular file fails and a symlink pointing at the source
reads as already published, and neither has been checked here.
