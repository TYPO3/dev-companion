# Rewrite `knowledge/documents/` in STE

The hints, the checklists and the pages `typo3_rule_lookup` serves are the prose
a caller reads as an instruction. They are procedures, so the measure is 20
words a sentence — `D-DOC-070`.

1. Run `bin/cli prose:check` and take the `knowledge/documents/` rows as the
   worklist.
2. Rewrite one document at a time. Keep every query a hint carries whole, and
   run `bin/cli hints:probe` on it after the rewrite, because the match is
   lexical and a rewrite can take a word the query needs.
3. Run `bin/cli knowledge:format` and `composer test` after each document.
4. Commit each document on its own.

Done when `bin/cli prose:check` names no file below `knowledge/documents/`.
