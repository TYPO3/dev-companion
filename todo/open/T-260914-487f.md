# Rewrite `skills/` in STE

`D-DOC-070` adopted ASD-STE100 for the whole corpus, and a skill is what a
caller imitates first (`D-DOC-068`). A skill is a procedure, so its measure is
20 words a sentence.

1. Run `bin/cli prose:check` and take the `skills/` rows as the worklist: the
   sentences over 20, the passive forms, the -ing forms.
2. Rewrite one skill at a time. Name who acts. Give one instruction a sentence.
   Keep every tool name, every id and every path as it is.
3. Run `bin/cli prose:format skills/` and `composer test` after each skill.
   `SkillTest` holds what a skill may state.
4. Commit each skill on its own.

Done when `bin/cli prose:check` names no file below `skills/`.
