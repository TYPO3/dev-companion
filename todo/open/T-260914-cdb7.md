# Rewrite `scenarios/` and `todo/` in STE

The scenarios and the todos are the last two directories `Prose::documents()`
reads. A prompt in a scenario is a user's words and stays as it is; the
criteria, the readme pages and the todo bodies are this repository's.

1. Run `bin/cli prose:check` and take the rows for the two directories as the
   worklist.
2. Rewrite one file at a time. Keep every prompt and every recorded run's
   judgment as it is.
3. Run `bin/cli todo:check` and `composer test` after each file. Commit each
   file on its own.

Done when `bin/cli prose:check` names no file below the two directories.
