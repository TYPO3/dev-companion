# Rewrite the tool descriptions and the instructions in STE

The prose a client is handed at connect is the one surface `Prose::documents()`
does not reach: every `description` in `src/Tool/`, every field description in a
schema, and the `instructions` in `knowledge/server-scope.json`.
`bin/cli prose:check` prints them under "A client is handed", worst first — 316
sentences over 25 words on 2026-09-14.

1. Rewrite the descriptions one tool at a time. Keep every tool name a
   description names, because `ScopeTest` holds the pairs.
2. Keep the `instructions` inside the budget `R-ANS-013` sets.
3. Run `composer test` after each tool. `tests/Contract/` holds every schema.
4. Commit each tool on its own.

Done when the "A client is handed" heading in `bin/cli prose:check` prints zero
sentences over the measure.
