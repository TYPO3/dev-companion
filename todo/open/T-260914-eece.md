# Rewrite the comments below `src/` and `tests/` in STE

The comments are prose too, and AGENTS.md says the prose rules hold for them.
`bin/cli prose:check` counts their share and the retold ones, and reads no
sentence in them, so the worklist is a read of each file.

1. Read one class at a time, `src/Upkeep/` first, because those comments
   describe the checks a session runs.
2. Rewrite each comment: name who acts, 25 words a sentence, present tense.
   Where a comment names a decision and retells it, cut the retold half.
3. Run `composer ci` after each directory. Commit each directory on its own.

Done when a read of `bin/cli prose:check`'s retold list is empty and each class
has been read once.
