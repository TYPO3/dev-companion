# a change read by name lists the changes its messages name

Judged on 2026-09-15 as step 1b, `D-ANS-156`: the chain is empty for
alternatives pushed as separate changes, and the number in a message is the only
link. Give the answer of `typo3_gerrit_lookup` for a change read by name a list
beside `chain`, `namedInMessages`: every change number and review URL the
messages name, each resolved against the review server to its number, subject,
status and URL, minus the change itself and the chain. A number that resolves to
nothing drops out, which is how a Forge number in the same digits stays out.
Read it whatever `messages` says, since the point is the reader who did not ask
for the log. The fixture is changes 95814, 95817 and 95818, whose messages name
each other and which carry no topic. `against`, the comparison of two changes,
waits on the maintainer's answer in the same entry and is not this step.
