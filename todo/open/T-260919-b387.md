# A decision holds the text block as prose rather than the serialized JSON

Write the decision. The specification says a tool that returns
`structuredContent` SHOULD also return the serialized JSON in a text block, on
2025-11-25 and on 2026-07-28 alike. `Sdk\ToolHandler` sends the tool's rendered
text instead, and AGENTS.md holds an answer's text to say what its schema says.
Nothing in `decisions/` names the SHOULD it departs from. So a reader who checks
the server against the specification finds a deviation nobody has stated. The
entry says what the prose buys the model over a JSON dump. Its **Wrong if** is a
client that shows the model the text block alone and reads nothing out of it.
