# Initialize carries the display fields the SDK can send

Fill in what `Server\Factory` leaves empty on the wire.
`Builder::setServerInfo()` takes `title`, `description` and `websiteUrl`, and
the docs URL in `composer.json` is the website. The arguments of the
`commit_message` prompt arrive with a name and `required` alone. The SDK reads
an argument's description from the `@param` tag of the closure, in
`Mcp\Capability\Discovery\Discoverer`, and the closure in `Factory::create()`
has none. Add the tags, and assert the descriptions in
`StdioServerTest::theCommitMessageGuideIsAvailableAsAPrompt`. An icon is
optional. Where one goes in, it is a `data:` URI from `documentation/images/`,
because a stdio server has no origin a client can fetch from.
