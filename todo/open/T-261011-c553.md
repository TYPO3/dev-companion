# A PHP without curl stops the server at start

`Upstream::check()` runs in `Server\Entrypoint::run()` before the transport
starts. Where the kept answer is absent, older than an hour, or `unavailable`,
it asks GitHub through `Http\Fetch::read()`. On a PHP without curl, that read
throws the `RuntimeException` that names ext-curl. Nothing catches it, and the
server exits with 255 before the first request.

`StdioServerTest::aPhpWithoutCurlIsRefusedWithTheExtensionNamed` holds the
opposite and fails only where the kept answer makes the server ask. The PHP 8.4
job of run 37581763708 failed there on 2026-10-07 and passed on the rerun. So
the test passes by the order of the suite and the state of the GitHub API.

Make the start survive a failed read, so `Upstream` reports `unavailable`. Then
make the test independent of the kept answer, so it fails every time the start
asks and dies.
