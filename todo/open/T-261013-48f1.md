# Every environment turns a deprecation into an exception

All four `e-site-*` environments carry `SYS/exceptionalErrors` at 4096, so a
deprecation in `src/Installation/probe.php` passes them in silence. Issue #12
showed one: `setAccessible()` failed on PHP 8.5 only at 12290, the value of
TYPO3's Debug preset. Make `Environments::build()` set 12290 after the setup
step, and hold that step with a test. `configuration:set` does it on 14.3 and
main, but 12.4 and 13.4 have no `configuration` commands, measured on
2026-10-13. Then set 12290 in the four environments that exist already.
