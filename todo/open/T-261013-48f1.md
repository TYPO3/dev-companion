# Every environment turns a deprecation into an exception

The build and the resume of `bin/cli environment:create` set
`SYS/exceptionalErrors` to 12290 now. The four `e-site-*` environments below the
main checkout's `.environments/` still carry 4096. A worktree session cannot
reach them, because they are the main checkout's. So in the main checkout, run
`bin/cli environment:create E-SITE <version>` for 12.4, 13.4, 14.3 and main.
Then check that `config/system/settings.php` in each says 12290, and stop the
projects that were stopped before.
