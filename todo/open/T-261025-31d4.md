# Name the tools a new sitepackage is started with

Add a hint to `knowledge/hints/sitepackage.json` that names the tool each part
of a new sitepackage comes from. The Site Package Builder at get.typo3.org
creates the extension, and `friendsoftypo3/kickstarter` writes the set with
`make:site-set` and `make:site-settings-definition`. That package's
`make:site-package` returns `Command::FAILURE` on v14 in 0.4.0 and in 1.0.0, and
runs in 0.3.5, which requires `typo3/cms-core ^13.4.3`. `b13/make` states that
it creates neither a site package nor an Extbase extension. Bind every statement
that holds per major with `since` and `until`. Settle in the same step where the
evidence for a third-party tool lives, because `.checkouts/` holds the core
alone.
