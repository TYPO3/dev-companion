# Route a sitepackage task to the hints that answer it

Add a `sitepackage` entry to `knowledge/task-intents.json`, because the five
hints in `knowledge/hints/sitepackage.json` reach no task today. Give it the
words a caller types: sitepackage, site package, theme extension, new site.
Route its checklist to those five hints and to `sitepackage-start`, which names
the tools a new one is started with. Run `bin/cli hints:coverage` before and
after, and name in the commit what the entry reached that nothing reached
before.
