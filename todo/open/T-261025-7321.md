# Write the case for a sitepackage built from nothing

Add a contract case below `scenarios/contracts/site-developer/` for the task
that starts with no sitepackage at all. `SITE-01` asks for a site configuration
and templates the caller already has, and it is `held`. No case asks an agent to
create the extension, the set and the page templates from nothing, which is the
step a new user meets first. Write the prompt as a user types it and the
criteria a person judges, as `scenarios/readme.md` states. The case is what
decides `T-261025-2da7`: it shows either that the skills that exist carry the
task, or where they come up short.
