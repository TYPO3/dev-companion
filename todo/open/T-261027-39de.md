# Say when a Forge or Gerrit answer was read

An answer from `typo3_forge_lookup` and `typo3_gerrit_lookup` carries when the
issue or the change last moved (`updatedOn`, `updated`). It does not say when
the server read it, so a caller cannot tell a fresh read from one `Http\Recent`
held for up to 300 or 30 seconds. Add a `readAt` field to both output schemas,
filled from the moment `Recent::hold()` stored the read or the fetch happened,
and put it in `Result\Schema` because two tools answer with it. A measurement
of 2026-10-27 over 140 Forge and 202 Gerrit calls in the maintainer's sessions
found no repeated call inside either hold. Write that as a "Since then" on
`D-ANS-049`, which says nothing had measured it.
