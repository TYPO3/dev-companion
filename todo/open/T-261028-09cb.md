# No tool reads the text of a changelog entry

In the second REVIEW-02 run of 2026-10-28, `typo3_changelog_lookup` returned
Breaking-110702 with an empty `migration`. `typo3_documentation_lookup` then
refused its URL: "page must be a canonical result URL for targetVersion".
`Manual\\Documentation::page()` accepts the four manuals alone. So the session
gave up on the v15 question. Check why the migration came back empty, and decide
whether a changelog entry's page is read through `typo3_changelog_lookup` or
through `typo3_documentation_lookup`.
