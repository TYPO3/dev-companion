# A review skips the changelog of a declared major it does not run

The base exempts a review from the deprecation sweep. The third REVIEW-02 run of
2026-10-28 then left the declared v15 support unchecked and never asked the
changelog by identifier. The second run had found Breaking-110702 against
`Classes/Service/ImageInfoService.php` that way. Decide whether a review of a
range that declares a major it does not run owes one changelog query per
identifier it touches, and where the brief says so.
