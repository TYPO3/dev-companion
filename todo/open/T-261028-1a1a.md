# The audit surface list has no distribution surface

The second REVIEW-02 run of 2026-10-28 took the `surfaces` of the audit brief as
its whole work list. That list names no distribution surface, although
`knowledge/hints/distribution.json` and `typo3-distribution-content` exist and
`typo3_extension_describe` listed `Initialisation/data.xml`. So the run never
read `Initialisation/`, and the top finding of the run before it, the demo site
imported into every installation, went missing. Add the surface to the audit
intent where the checkout carries one, and say in the brief that the list is a
floor, not the whole review.
