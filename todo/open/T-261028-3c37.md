# A secret's history is dated by the file it now stands in

Both REVIEW-01 runs of 2026-10-28 dated the committed encryption key in
`site-events` to 2023. They ran
`git log -S <key> -- config/system/settings.php`, which misses the file it stood
in before the rename. A search over all paths finds e287c12 of 2018-12-12. Where
the exposure of a secret turns on its date, a hint can say to search its value
with no path, or with `--follow`. Decide whether the security hint carries it.
