# A wait on runTests.sh by pgrep -f never ends

The REVIEW-03 session of 2026-10-28 waited on its background suites with
`until … ! pgrep -f "runTests.sh"; do sleep 3; done`. `pgrep -f` matches the
loop's own command line, so the loop never ended and the headless client hung
for 26 minutes after its answer. The client had already reported the background
task complete. Say in the invocation notes of `typo3_test_run_guide`, or in
`skills/base.md`, how a session waits for a run: on the background task's own
completion, or on an exit marker in its output, never on a process search for
the script name.
