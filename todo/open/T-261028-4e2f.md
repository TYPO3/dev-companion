# The audit head has no form for a project with several extensions

`site-events` carries a root package and two project extensions. The third
REVIEW-01 run of 2026-10-28 wrote its head fields with several values in
parentheses, for example `^14.3 (project); ^13.4 || ^14.3 (events_sitepackage)`.
That breaks the rule that a head field holds one value. The skeleton asks for
one package. Give it a form for a project with several own extensions, for
example one row per package.
