# The Checkout head field has three values nobody defines

`skills/typo3-extension-health/references/report.md` offers `standalone`,
`inside an installation` and `the installation` for **Checkout**. No skill,
decision or page defines them. `typo3_project_describe` answers
`kind: composer-project` with the extension at the root, and nothing maps that
onto the three values. So the third REVIEW-02 run of 2026-10-28 called the
standalone `bootstrap_package` repository `the installation` and missed met 1.
Define the values in the skeleton, or have `typo3_project_describe` answer the
value itself.
