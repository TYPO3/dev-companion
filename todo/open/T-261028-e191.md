# A functional test user without workspace_perms writes in workspace -99

The REVIEW-03 session of 2026-10-28 found it on the reviewed patch. A
functional-test backend user with no `workspace_perms` works in workspace -99
where EXT:workspaces is loaded. MariaDB then rejects `t3ver_wsid` with SQLSTATE
22003, while SQLite passes. The session showed it with a MariaDB run and a
probe. Verify it in `.checkouts/` on every covered line before it goes into
`datahandler-testing`, bound where it differs.
