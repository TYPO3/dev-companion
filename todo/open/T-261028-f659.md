# Instructions in the text half alone never reach Claude Code

The maintainer answered on 2026-10-28: (c). A sentence about one value takes a
string field beside that value, as `beforeYouRun` and `surfacesOwed` do. The
rest, and the notices `Sdk\ToolHandler` prepends, go into one shared `owed` list
that `ToolResult` carries and every output schema declares.

Claude Code hands the model the data half (`D-EVI-011`), so a sentence that
stands only in a tool's text reaches no Claude Code session. `R-ANS-002` forbids
that. The brief's surface instruction moved into `surfacesOwed` on this branch.
A sweep of `src/` on 2026-10-28 found the same gap elsewhere, and the clear
cases are below. Each line names where the sentence stands and what the data
carries instead.

- `Sdk\ToolHandler::handle()` prepends `CodeAge::NOTICE` and
  `Upstream::notice()` to the text alone. A Claude Code session never hears that
  the server is stale or behind.
- `TaskGuide`: `HINTS_SOURCE`, `HINTS_TRUNCATED`, `HINTS_COMPLETE`, the call
  half of `HINTS_OMITTED`, `SKILLS_OWNING`, `SKILLS_IN_ORDER`, the command in
  `SKILLS_STALE`, the line for work that changes nothing, `UNCERTAIN_NOTICE` and
  the checks sentence outside the core.
- `CommitMessageGuide::CORE_GUIDE`.
- `LabelLookup::SOURCE_LANGUAGE` and the reuse boundary where `resource` is
  null.
- `ChangelogLookup`: the miss pointers to `typo3_documentation_lookup` and the
  changelog page, the Gerrit pointer on a body match, and the advice where every
  hit comes from one system extension.
- `ExtensionDescribe`: the schema lookup per table, `FLEX_FORM_CALL`, the
  deprecated-file pointer, the source-language pointer, and the workflow skill
  where manual or tests are missing.
- `ForgeLookup`: the mention warning, the advice on an empty search, the
  `reportedBy` and `assignedTo` hint, `workflow()`, and the follow-up calls.
- `GerritLookup`: `workflow()`, the review-skill line, the hint and test-run
  pointers, `releaseClaim`, the `noIssueNamed` text and the `messages` advice.
- `HintLookup`: the documentation lookup call after `bestCoverage`.
- `MatchedHints`: the worked example and its `typo3_reference_list` pointer.
- `TestRunGuide`: `SCRIPTS_GUIDE`, `BROWSER_CHECK_GUIDE`,
  `RENDERING_PROBE_GUIDE` and the hint ids outside the core.
- `ProjectDescribe`: the `composer install` command, the test-run and hint
  pointers, and the changelog pointer.
- `RuleLookup`: the withheld-document pointers and the miss advice.
- `Prose::BOUND_ELSEWHERE` and `Prose::BOUND_TO_A_SUITE`.
- `IssueReportGuide`: "Nothing was filed" beside the draft `url`.

A sentence whose substance a data field already carries stays out of the list,
such as a retry where the data holds the narrowing counts. The answer to
`waitingOn` decides the shape. A test over every tool then holds it: each
imperative sentence in a text also stands in the data.
