# A session that gets the skill URI reads it in half the opencode runs

`D-DIS-034` holds the evidence under **Measured again on 2026-10-29**. In
opencode 2.1.4 on `opencode/big-pickle`, four of four runs without skill files
called `typo3_task_guide`. Each got a `skillsOwed` that names
`typo3://skill/typo3-content-element-development/SKILL.md`. Two read it and two
did not.

1. Read the two runs that did not, and find what they did with the line. The
   transcripts are not kept, so run the measurement again in the same setup and
   keep the JSON output of each run.
2. Establish whether the line loses to something above it in the same answer.
   `skillsOwed` stands after `skills` in the data and after the `Recognized as:`
   line in the text. `guides` follows it with a `typo3_rule_lookup` route that
   needs no resource list.
3. Change the wording or the order only where a run shows the cause. Then
   measure again, and record the count in `D-DIS-034`.

The priority is `normal`, because a session without the skill ended on a site
that served an exception.
