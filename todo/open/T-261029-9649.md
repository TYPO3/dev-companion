# A breaking entry above the installed major is cleared by a check on it

The fifth REVIEW-02 run of 2026-10-28 got Breaking-110702 with `touches` naming
`Classes/Service/ImageInfoService.php`. It cleared every v15 entry because
PHPStan showed no affected calls, and that PHPStan ran against the installed
14.3.7. On v15 `getProcessedFile()` returns `ProcessedResourceInterface`, while
`ImageInfoService.php:40` still declares `?ProcessedFile`. Say in the brief's
owed line and in the skill that a check on the installed major cannot clear an
entry above it. An entry whose `touches` name a file is read, or it stands under
**Open**.
