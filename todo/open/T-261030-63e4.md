# A large answer takes a size switch where a measure shows the saving

The self-assessment of 2026-10-29 proposes `detail: concise|full` on
`typo3_project_describe`, `typo3_task_guide`, `typo3_gerrit_lookup` and
`typo3_forge_lookup`. `D-ANS-087` declines a selection, because a call costs
more than the bytes. So measure first: run
`bin/cli tools:tokens typo3_task_guide '{"task":"add a backend module to my extension"}'`
and the same for the three other tools. Then record in `D-ANS-087` what share of
the session each answer took and whether a later call read it again. Build the
switch only where an answer costs a session more than one call would. Revise
`D-ANS-087` in the same commit.
