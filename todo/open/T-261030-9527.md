# A large answer links the typo3:// resources it names rather than quotes them

The MCP specification lets a tool return `resource_link` blocks. `D-EVI-011`
read that Claude Code hands the model the blocks of `content` that are not text,
so a link reaches the model there. What it costs is not measured. Add one
`resource_link` per guide to `typo3_project_describe` on a branch, then run
`bin/cli tools:tokens typo3_project_describe '{}'` there and on `main`. Record
in `D-EVI-011` whether the session read a linked resource, and in which client.
Keep the links only where they save a call or a quoted text, and drop the
quoted `guides` text in the same commit.
