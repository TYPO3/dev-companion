# The step every card carries stands over the prose measure

`Card::STEP` is four sentences of 41, 38, 35, and 35 words. The measure is 25.
So `bin/cli prose:check` reports every freshly recorded feedback's card, and a
card nobody has judged yet is the worst file in the repository for sentence
length.

That makes the report lie about where the prose is worst. Three cards written
on 2026-10-30 and 2026-10-31 each arrived at the head of that list, above the
files a reader would want to see.

1. Read `Card::STEP` against the measure and shorten each sentence to it. The
   step says four things: judge before fixing, make the change in the same run
   where nothing is left to establish, write the judgement into `decisions/`,
   and read `documentation/records/judging.rst`. Each is a sentence.
2. Settle what happens to the cards already in the queue. `Todo::folded()`
   compares a body against the constant with `!==`, so a card written under the
   old text stops matching the moment the constant changes. `D-FBK-040` rests
   on that comparison, and
   `TodoTest::theCardAJudgementReplacedIsFoundByTheStepItStillCarries` holds
   it.
3. Decide between a migration and a tolerance. Either rewrite the open cards in
   the same commit, or let `Todo::folded()` accept a body that matches any step
   the repository has shipped. The second needs the old text kept somewhere,
   which is a cost the first does not have.
4. Hold the new text to the measure with a test, so the next edit of the step
   cannot reintroduce the report.

The step is prose this repository writes about itself, so the rule in
`AGENTS.md` holds for it. A sentence of 41 words in a file every card carries
is the one place the corpus breaks its own measure by design rather than by
oversight.
