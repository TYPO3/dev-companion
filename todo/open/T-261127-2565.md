# Replace "owns" outside the skills with the word it means

The pilot of `D-SKL-112` replaced "owns" in the skills where it stated a scope.
It still stands in the compatibility line every skill carries, in AGENTS.md, in
`src/` and in `knowledge/server-scope.json`. It means three things there. A
skill covers a task, a tool answers a question, and a skill works on its own
files. Write the word each place means. Keep `owner` where it names the Gerrit
field. The compatibility line is held by
`SkillTest::everySkillSaysWhichServerItNeeds`, so read that test first.
