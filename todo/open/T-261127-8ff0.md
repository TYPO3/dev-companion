# Route SKILL-13's own words to the patch checkout

The prompt of `SKILL-13` confirms `tests`, so `typo3_task_guide` names
`typo3-extension-testing` for it. The `patch-checkout` needles "pull down" and
"patch from review" match, but `TaskIntents::scoped()` makes the intent weak,
because the text names no core work. With a path below `typo3/sysext/`, the
brief names `typo3-core-patch-checkout` and `typo3-core-patch-development`. A
session that fetches a patch knows no path before the fetch. The next step is to
decide what counts as core evidence for a fetch from review.typo3.org, and to
measure it with the case's prompt. Then add the case as a row of
`ScenariosTest::theCasesWhoseOwnWordsHaveToReachAnIntent`.
