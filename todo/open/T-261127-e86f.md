# Read the review changes through providers, Forger first

`typo3_gerrit_lookup` still reads review.typo3.org alone. Give it the shape
`D-ANS-197` gave the issues: a change provider interface, `Gerrit` and a Forger
provider over `/api/v1/changes`, and a class that builds the answer from the
first one that answers. Forger serves the review lists, the path filter, the
votes, the chain and the conflicts. Check which of the six ways in it cannot
serve before the interface takes a method: a lookup by commit hash, the comment
threads, and the CI jobs that failed a patch set. `Gerrit::tracker()` then reads
issue fields through `IssueTracker` rather than `Forge`.
