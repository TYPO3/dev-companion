# Read the contract cases no test can hold

Read the cases the command above prints, which are the ones whose `Held by` says
`not guarded`, and what they are all waiting for is the same thing: whether a
session does what the case says, which no test here reaches. `SKILL-09` is where
to start, because it says in as many words that it measures the rest.
`SKILL-12`, `SKILL-13` and `SKILL-14` carry cards of their own in
`todo/waiting/` and are answered there rather than here. Read each against the
skills and the answers as they are today, not against the last reading: the
proxy is a sentence in a file that a reorganization satisfies while the
behaviour goes. What a reading finds is a feedback, a requirement, or a line in
the case saying it still holds and on what evidence — and the date above, which
is what keeps two sessions from re-reading the same files.
