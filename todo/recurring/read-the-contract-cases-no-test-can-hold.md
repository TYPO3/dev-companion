`not guarded`. They all wait for the same thing, whether a session does what the
case says, which no test here reaches. `SKILL-09` is where to start, because it

reorganization satisfies while the behaviour goes. What a read finds is a
feedback, a requirement, or a line in the case that says it still holds and on
what evidence. And the date above, which is what keeps two sessions from a
second read of the same files.
