# Have a review name the failure it shares instead of wording it again

Record one forward run per review on this branch, the way
`documentation/records/forward-runs.rst` says:
`bin/cli scenarios:show REVIEW-01` prints the prompt to paste and the criteria,
the run goes into `scenarios/runs/`, and `bin/cli scenarios:check` reads it
against the wording as it stands now. The edit is done. Each review names the
failures every review shares by the names `scenarios/forward/readme.md` gives
them and words only its own, so the three run records no longer read as the
reviews do, and `ScenariosTest::everyRecordedRunHoldsUpToItsScenario` is red on
this branch until the runs are recorded.
