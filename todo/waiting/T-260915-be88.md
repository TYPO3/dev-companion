# a comparison of two changes without a fetch

Judged on 2026-09-15 as step 1b and proposed, `D-ANS-156`. Where the answer is
yes: add `against` to `typo3_gerrit_lookup`, taking a change number or Change-Id
beside `change`, and answer `differs`, the paths whose content is not the same
at the two current patch sets, each with its insertions and deletions on either
side. Read the two file lists first and the content only for the paths both
touch, since a path one of them leaves alone differs by definition. Say where
the review server did not answer a content read, and return the two fetch refs
side by side in every case.
