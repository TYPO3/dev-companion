# Read confval details and the manual list from docs.typo3.org

Check each shape in `waitingOn` against a served file first, because nothing was
built when a session wrote it. Then `Manual\Manuals` reads the list from
`manuals.json` in place of `knowledge/manuals.json`, and only the `searched`
flag stays here. `bin/cli manuals:check` then has nothing to check, and the
session removes it. `Manual\Documentation` answers a `std:confval` hit with the
type, the default and the summary from `confvals.json` rather than a page read.
It reads `Default`, `Required` and `Type` under `fields` too, where the TCA
reference writes 116 options with capitals until its cleanup lands. A 404 for
either file means that version was rendered before the release.
