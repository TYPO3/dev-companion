# Read the manual list from docs.typo3.org

`manuals.json` stands at
`https://docs.typo3.org/h/typo3/docs-homepage/main/en-us/manuals.json`, beside
`mainmenu.json`. It keys each manual with `name`, `group` and `versions` of
`version` and `base`, and lists four manuals `knowledge/manuals.json` lacks:
`t3exceptions`, `t3translate`, `t3content` and `t3writing`. Once it keys every
manual by its declared shortcode, make `Manual\Manuals` read it in place of
`knowledge/manuals.json`, keep only the `searched` flag here, and remove
`bin/cli manuals:check`. The host names two searched manuals differently, so the
rank `D-ANS-065` measured is read again with the host's titles.
