# Decide the sitepackage skill on what the run shows

Write `skills/typo3-sitepackage-development/` where that run shows that the
skills in `skills/` fail to carry the task.
`documentation/contributing/writing-a-skill.rst` states the bar a domain meets
before it earns one. Five skill descriptions name a sitepackage today as a
package they act on, and none of them builds one, which is why a caller finds no
skill for the step. Shape the skill around what the run came up short on rather
than around the domain. Show the maintainer the `SKILL.md` and every reference
before the commit, and ask by name which step is absent.
