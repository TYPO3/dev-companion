# Nothing says which class holds a database query

A session on an update project put a private `findBy` method into a service. The
two greenfield runs of 2026-10-29 split on the same question, and one of them
wrote no repository at all. This corpus names a class for a query once, and only
for the route that writes no PHP.

1. Read the run this feedback came from before anything else. Name the project,
   the model, and whether the session called this server at all. A session that
   never asked is not evidence that the answer was missing, and the feedback
   carries no `directory:` until somebody has read it.
2. Say what a repository buys when an extension writes PHP of its own. That is
   one place per table, the restrictions set once, and a seam a test replaces.
   Say it as a project convention, because the core queries from controllers,
   services, and upgrade wizards as well as from repositories.
3. Say that a query method is not private. A private `findBy` is a query the
   next caller writes again, and a method no test reaches directly.
4. The maintainer settled the boundary on 2026-10-30. A private `findBy` is poor
   in general, because the repository cannot be used then, and no rule forbids
   it. So a statement says it as a recommendation, not as a rule. The layout of
   somebody's own `Classes/` is architecture rather than TYPO3, and this server
   has answered for TYPO3.
5. Decide where the statement lands. A hint a build task reaches, the
   `typo3-extension-health` audit, or both; the audit already reviews a
   repository against its checkout.
6. Hold the route with a test, so the statement reaches the intents a session on
   an existing project reads.

Verify the core measurement against `.checkouts/` before it goes into
`knowledge/`. The figures in the feedback come from the core a trial installed,
which is evidence of the gap rather than evidence of the fact.

The judging step comes first, as `documentation/records/judging.rst` says. The
feedback stays open until the commit that ships the statement archives it.
