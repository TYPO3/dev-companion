# A large answer takes a size switch where a measure shows the saving

`bin/cli tools:measure` on 2026-10-30 read the recorded answers at 3,000 to
5,000 tokens a call for `typo3_task_guide`, `typo3_project_describe` and
`typo3_test_run_guide`. One answer costs far less than the call `D-FBK-020`
measured, but every later call reads it again. Run the same task twice, once
with the whole answer and once with a concise one cut by `tools:proxy`. Count
the calls each session made for what the concise answer dropped, and the input
tokens of the session. Record both in `D-ANS-087`, and build the switch only
where the concise session is cheaper.
