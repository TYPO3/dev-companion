# A large answer links the typo3:// resources it names rather than quotes them

The MCP specification lets a tool return `resource_link` blocks, and `D-EVI-011`
read that Claude Code hands the model the blocks of `content` that are not text.
Add one `resource_link` per guide to `typo3_project_describe` on a branch. Run a
task that needs one of the guides there and on `main`. Record in `D-EVI-011`
whether the session read the linked resource and what the session cost. Keep the
links only where they save a call or a quoted text, and drop the quoted `guides`
text in the same commit.
